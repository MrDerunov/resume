Legacy Modernization at Revizto

Context

A large BIM/CAD desktop platform with 10+ years of legacy code. Core business logic tightly coupled to UI. Domain knowledge siloed in senior developers' heads.

Problem

Adding features took weeks due to ripple effects. No automated tests meant regression bugs on every release.

Solution

Reverse-engineered legacy code into documented domain modules. Introduced service layer separating business logic from UI. Built automated test harness around critical workflows. Applied AI-assisted analysis to accelerate knowledge recovery.

Result: Significantly fewer regression bugs. 60%+ test coverage on critical paths. 50+ business rules formalized.

Smartcat Drive — New Platform Core with Hierarchical Structure

Context

Localization platform stored thousands of files as flat lists. Every file operation was individual and manual.

Problem

Flat file lists didn't scale. Customers managed thousands of files with no organizational structure. Bulk operations (move, copy, delete, tag) were impossible. No API existed for file and folder operations — every interaction went through the UI.

Solution

Built Smartcat Drive — a new core platform kernel replacing flat lists with hierarchical folder/file structure. Designed an abstract DOM-like model where any entity (file, folder, external system object) is a node in a tree. Built a dedicated Drive API for programmatic file/folder interaction. Implemented bulk operations across the tree structure.

Result: The platform got a proper hierarchical file system kernel. Files and folders became abstract nodes — any external system object could be represented in the tree. The Drive API enabled programmatic interaction with the file structure. Bulk operations automated key file workflows.

Media Workflow Automation

Context

Localization platform expanding into multimedia. Customers needed video/audio localization — transcription, subtitles, dubbing. Multi-GB files with complex processing.

Problem

No media processing infrastructure. Video files too large for synchronous processing. Multiple third-party tools needed orchestration.

Solution

Built Docker-based media processing microservices with async job queues. Format-agnostic pipeline: ingest → transcribe → translate → generate subtitles/dubbing → deliver. AST-based subtitle format conversion.

Result: Introduced media processing capability from scratch — the platform had no video/audio/subtitle support before. Supported virtually any media format via ffmpeg-based pipeline. Enabled new revenue stream.

Electronic Signature & Government Document Automation

Context

Engineering design institute required to submit documentation to government review with GOST electronic signatures. Multi-GB project files with strict format requirements.

Problem

Manual preparation took 3-5 days per submission. Russian GOST cryptographic standards incompatible with Western PKI. Signature placement errors caused rejection.

Solution

Built automated document pipeline: CAD data → PDF → structured package → GOST electronic signature → government portal submission. Integrated Russian cryptographic libraries with .NET workflow engine.

Result: Processing from 3-5 days to under 2 hours. 80% fewer document rejections. Thousands of documents processed.

Integration Hub — From Months to 2 Weeks per Integration

Context

Localization platform needed to integrate with 15+ external systems. Each integration took months of custom development with tightly coupled, one-off adapters. Adding a new system was a major engineering investment.

Problem

Integration development was slow (months per system), brittle under API changes, and each adapter had no shared infrastructure. This blocked platform growth and customer onboarding.

Solution

Built 2 generations of integration hub: v1 — quick Kubernetes-based prototype proving the hub concept; v2 — hierarchical provider architecture with shared base classes, standardized authentication flows, and pluggable data transformers. Each new integration becomes a provider implementing well-defined interfaces.

Result: New integration time dropped from months to 2 weeks. 15+ integrations unified under single architecture with web UI for managing and monitoring all external system connections. Old brittle adapters fully deprecated. Comprehensive autotests ensure reliability across all external system interactions.

CadFerma — Multi-CAD Validation Platform

Context

Engineering design institute used multiple CAD tools (Revit, Civil 3D, AutoCAD) for railway, highway, building, and structure design. Each tool had its own proprietary format and validation logic. Engineers manually checked designs across tools — slow, error-prone, and inconsistent.

Problem

No unified way to validate engineering data across different CAD systems. Each CAD tool operated in isolation. Validation rules were applied manually per tool. Switching between tools to cross-check a single design took hours.

Solution

Built CadFerma - a web service orchestrating multiple CAD applications (Revit, Civil 3D, AutoCAD) under a single plugin-based interface. It loaded models from each tool, ran cross-tool validation checks, and produced unified compliance reports, replacing hours of manual cross-referencing.

Result: Engineers could validate designs across multiple CAD tools through a single web interface. Cross-tool validation time dropped from hours to minutes. Automated checks replaced manual cross-referencing. Plugin architecture allowed adding new CAD tools and validation rules without changing core service logic.
